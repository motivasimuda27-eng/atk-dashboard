========================================
ATK DASHBOARD - WINDOWS SILENT MODE
========================================

PERUBAHAN UTAMA:
================

Server sekarang berjalan di BACKGROUND tanpa menampilkan CMD window!

✅ KEUNTUNGAN:
- Tidak ada window yang mengganggu user
- Server tetap berjalan di background
- Logging otomatis ke file
- Lebih professional dan user-friendly

📁 FILE BARU:
=============

1. start_production_silent.vbs
   - VBScript untuk menjalankan server tanpa window
   - Menampilkan popup notification saat server start

2. view_logs.bat
   - Utility untuk melihat log files
   - Bisa monitor real-time

📝 FILE YANG DIUPDATE:
======================

1. start_production.bat
   - Sekarang menggunakan pythonw.exe (background mode)
   - Memanggil VBScript untuk run tanpa window
   - Menampilkan popup notification

2. waitress_server.py
   - Logging ke file: production.log
   - Error logging ke: production_error.log
   - Tetap bisa monitor aktivitas server

3. stop_production.bat
   - Update untuk bisa stop pythonw.exe processes
   - Support multiple kill methods

4. status_production.bat
   - Deteksi pythonw.exe (background mode)
   - Tampilkan last log entries
   - Check error log

🚀 CARA MENGGUNAKAN:
====================

1. START SERVER:
   start_production.bat
   
   - Popup notification akan muncul
   - Server berjalan di background
   - TIDAK ADA window CMD yang muncul!

2. CEK STATUS:
   status_production.bat
   
   - Lihat apakah server running
   - Lihat PID dan process type
   - Lihat log entries terakhir

3. LIHAT LOGS:
   view_logs.bat
   
   - Pilih log yang ingin dilihat
   - Monitor real-time
   - Check errors

4. STOP SERVER:
   stop_production.bat
   
   - Menghentikan background process
   - Multiple kill methods

📊 LOG FILES:
=============

- production.log          → Semua aktivitas server
- production_error.log    → Hanya error (jika ada)

Monitor real-time:
  view_logs.bat → pilih opsi 3 atau 4

🔍 TECHNICAL DETAILS:
=====================

- Menggunakan pythonw.exe instead of python.exe
- pythonw.exe = Python without console window
- VBScript runs process with WindowStyle = 0 (hidden)
- Waitress logging redirected to files
- Process monitoring via port 5000

✅ TESTED ON:
=============

- Windows 10
- Windows 11
- Python 3.8+
- Waitress 3.0.0

🆘 TROUBLESHOOTING:
===================

Q: Popup notification tidak muncul?
A: Normal. Popup hanya 5 detik. Check status_production.bat

Q: Bagaimana tahu server sudah running?
A: Jalankan status_production.bat atau buka http://127.0.0.1:5000

Q: Server tidak bisa di-stop?
A: Buka Task Manager → Cari pythonw.exe → End Task

Q: Mau lihat log real-time?
A: Jalankan view_logs.bat → Pilih opsi 3
